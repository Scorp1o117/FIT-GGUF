# FIT-GGUF Brand Mark

The mark expresses the product in one motion: a fixed memory-budget frame,
a geometric `F`, and one detached signal-orange bar completing the exact fit.

## Files

- `fit-gguf-logo-dark.svg` — horizontal lockup for dark backgrounds.
- `fit-gguf-logo-light.svg` — horizontal lockup for light backgrounds.
- `fit-gguf-mark-dark.svg` — icon-only mark for dark backgrounds.
- `fit-gguf-mark-light.svg` — icon-only mark for light backgrounds.

All lettering is outlined geometry; the SVGs have no external font dependency.

## Palette

- Graphite: `#111111`
- Instrument ivory: `#F4F1E8`
- Signal orange: `#FF5A1F`

Keep clear space around the logo equal to at least half the icon width. Do not
add a permanent line through the wordmark; a calibration rail may appear only
as a transient motion element in video.
